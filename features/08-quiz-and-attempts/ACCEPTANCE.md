# Acceptance criteria

- [ ] Questions are served without answers, proven by a recursive assertion
- [ ] Every supported question type is graded correctly, including partial answers
- [ ] Wrong answers return given, correct, explanation and review skills
- [ ] Attempts are single-submit, version-stamped and replayable
- [ ] `quiz.attempt.graded` carries accurate per-skill outcomes
- [ ] Loading, empty, error, success and disabled states implemented
- [ ] Quiz is fully keyboard operable; correctness is not colour-only; axe passes
- [ ] Ungraded question types are labelled rather than silently dropped
- [ ] Automated tests pass
