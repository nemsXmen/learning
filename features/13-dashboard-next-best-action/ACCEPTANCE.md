# Acceptance criteria

- [ ] Dashboard renders in one aggregated round trip and matches the contract
- [ ] A next best action is always present and always shows the engine's reason
- [ ] Today's plan respects the user's daily minutes target
- [ ] Onboarding, degraded, error, empty and all-caught-up states implemented
- [ ] No recommendation logic exists in `apps/web`
- [ ] Private routes are `noindex`
- [ ] Axe passes in both themes; keyboard path to the primary action verified
- [ ] Copy is data-backed and matches the tone of CDC §78
- [ ] Automated tests pass
