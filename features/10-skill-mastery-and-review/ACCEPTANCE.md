# Acceptance criteria

- [ ] Mastery and review scheduling update transactionally with the graded attempt
- [ ] All calculation delegates to `packages/learning-engine`; no formula in this module
- [ ] Every mastery change stores an explainable reason
- [ ] Weak-skill and due-review endpoints return ordered, explained results
- [ ] Replay from attempt history is idempotent and reproduces live state
- [ ] Empty and error states defined for the consuming surfaces
- [ ] Automated tests pass
