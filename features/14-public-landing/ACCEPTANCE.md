# Acceptance criteria

- [ ] `/` is static, server rendered, and renders all seven sections in both themes
- [ ] Metadata, `sitemap.xml` and `robots.txt` are complete and exclude private routes
- [ ] Copy makes no claim the product cannot back; no fabricated social proof
- [ ] Every CTA leads to `/register` or `/login`
- [ ] Unpublished paths are shown honestly as "bientôt" and are not clickable
- [ ] Built entirely from `packages/ui`; no duplicated primitive
- [ ] Axe passes in both themes; keyboard traversal verified; reduced motion respected
- [ ] No third-party script and no client-side fetch on first load
- [ ] Automated tests pass
