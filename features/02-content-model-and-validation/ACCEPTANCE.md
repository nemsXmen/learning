# Acceptance criteria

- [ ] Schemas cover frontmatter, quiz, skills, module and technology files
- [ ] Every issue code in the contract is produced by a matching fixture
- [ ] All issues are reported in one run, with path and line
- [ ] Seed content (3 JavaScript, 2 TypeScript chapters) validates and is complete per CDC §74
- [ ] `pnpm content:validate` fails CI on invalid content
- [ ] `docs/content-model.md` matches the implemented schema exactly
- [ ] Automated tests pass
