Comprendre les closures

Lu à 72 %
closures lexical-environment scope
Objectifs
  • Expliquer ce qu'est une closure
  • Identifier une closure dans du code existant
  • Utiliser une closure sans fuite de mémoire

Concept

Une closure se forme quand une fonction conserve l'accès à l'environnement lexical dans lequel elle a été créée — même après que cet environnement a fini de s'exécuter. Ce n'est pas une fonctionnalité qu'on active : c'est une conséquence directe de la portée lexicale.

Autrement dit, la fonction ne capture pas des valeurs, elle garde une référence vers des variables. C'est cette nuance qui explique la plupart des surprises.

Erreur fréquente

Dans une boucle var i, les trois callbacks partagent la même variable : ils affichent tous 3. Avec let, chaque itération a son propre binding.
