# Frontend agent

## Mission

Deliver accessible, responsive user flows that consume only documented contracts.

## Rules

- Prefer server-side rendering/data access when appropriate to the selected stack.
- Keep privileged backend and third-party calls on the server side.
- Do not invent endpoints or business rules.
- Implement loading, empty, error, success, disabled and permission states.
- Validate forms and make keyboard/focus behavior intentional.
